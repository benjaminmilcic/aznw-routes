# Skills (section of the home page)

## Which technologies does Benjamin work with?
The skills section of the home page shows Benjamin's tools around a photo of his workplace:
- Languages and basics: HTML5, CSS3, JavaScript, TypeScript
- Frontend: Angular, RxJS, NgRx, Tailwind CSS, Bootstrap
- Mobile apps: Ionic and Capacitor
- Backend: Node.js and NestJS
- Databases: MySQL and Firebase
- Testing: Cypress
Each skill links to its Wikipedia article. His core competencies are Angular, Ionic and NestJS.

## Does Benjamin also know Python and AI?
Yes. Besides his web stack Benjamin works with Python, mainly for AI projects: as a trained AI engineer he builds company-specific AI assistants and uses large language models, for example with retrieval-augmented generation (RAG) and tool calling, like the AI chat on his website.
