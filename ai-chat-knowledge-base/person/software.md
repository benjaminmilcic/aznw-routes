# Software setup

## Which software does Benjamin develop with?
Benjamin develops on two Windows 11 laptops (see his hardware) with this software:
- Editor: Visual Studio Code, with extensions for Angular, Ionic, Tailwind CSS, Prettier, GitHub Actions, Python and Jupyter, and PHP with Xdebug.
- AI coding assistant: Claude Code, in the terminal and as a VS Code extension.
- Version control: Git and the GitHub CLI.
- JavaScript and TypeScript: Node.js 24 with npm, the Angular CLI and the NestJS CLI; also Bun.
- Python: Python with uv, mainly for AI projects.
- Mobile apps: Android Studio for the Android builds of his Ionic apps.

## Which further tools does Benjamin use?
- Docker Desktop with Ubuntu under WSL (Windows Subsystem for Linux).
- Laragon for local PHP and MySQL development, and PostgreSQL tools.
- Postman for testing APIs.
- FileZilla and PuTTY for file transfer and SSH to servers.
- Ollama to run large language models locally.
- Figma for design.
- PowerToys for Windows.
- The browsers Chrome, Firefox, Edge and Opera for testing websites.
- LibreOffice as office suite.
