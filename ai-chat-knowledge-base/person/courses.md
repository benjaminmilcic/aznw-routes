# Courses

## Which online courses has Benjamin completed?
Benjamin learned modern web and app development and AI engineering mainly through Udemy courses, all of them in English:
- Angular – The Complete Guide (Maximilian Schwarzmüller)
- Angular (Full App) with Angular Material, Angularfire & NgRx (Maximilian Schwarzmüller)
- Ionic – Build iOS, Android & Web Apps with Ionic & Angular (Maximilian Schwarzmüller)
- NestJS: The Complete Developer's Guide (Stephen Grider)
- Cypress End-to-End Testing – Getting Started (Maximilian Schwarzmüller)
- Clean Code (Maximilian Schwarzmüller)
- AI Engineer Core Track: LLM Engineering, RAG, QLoRA, Agents (Ed Donner)

## Which Angular and Ionic courses did Benjamin take?
- **Angular – The Complete Guide** by Maximilian Schwarzmüller: building reactive web apps with Angular. Link: https://www.udemy.com/course/the-complete-guide-to-angular-2/
- **Angular (Full App) with Angular Material, Angularfire & NgRx** by Maximilian Schwarzmüller: a complete Angular app with Angular Material, Firebase (Firestore) and NgRx. Link: https://www.udemy.com/course/angular-full-app-with-angular-material-angularfire-ngrx/
- **Ionic – Build iOS, Android & Web Apps with Ionic & Angular** by Maximilian Schwarzmüller: native iOS and Android apps and Progressive Web Apps with Angular, Capacitor and Ionic. Link: https://www.udemy.com/course/ionic-2-the-practical-guide-to-building-ios-android-apps/

## Which backend and testing courses did Benjamin take?
- **NestJS: The Complete Developer's Guide** by Stephen Grider: building backend APIs with NestJS, TypeORM and TypeScript, including testing and deployment. Link: https://www.udemy.com/course/nestjs-the-complete-developers-guide/
- **Cypress End-to-End Testing – Getting Started** by Maximilian Schwarzmüller: designing and running end-to-end tests with Cypress. Link: https://www.udemy.com/course/cypress-end-to-end-testing-getting-started/
- **Clean Code** by Maximilian Schwarzmüller: writing readable, understandable and maintainable code. Link: https://www.udemy.com/course/writing-clean-code/

## Which AI course did Benjamin take?
**AI Engineer Core Track: LLM Engineering, RAG, QLoRA, Agents** by Ed Donner: an eight-week course in which you build and deploy eight LLM applications, covering generative AI, retrieval-augmented generation (RAG), fine-tuning with LoRA/QLoRA and AI agents. Link: https://www.udemy.com/course/llm-engineering-master-ai-and-large-language-models/
